## Acquisition policy

Run `scripts/acquire-official-resources.sh`. It downloads into the ignored
`artifacts/official/` directory, verifies the immutable starter archive, Node
distribution, and pinned Codex package after download and before any reuse,
extracts the starter MIT licence, snapshots the public event/submission-help
surfaces, and writes a retrieval-specific checksum manifest. It uses no login,
cookie, token, or API key.
